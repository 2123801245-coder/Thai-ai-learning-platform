## 二、重新规划：免费 / VIP 分层

### 2.1 设计原则

1. **免费层要能完成「第一个正循环」**：拼音 → 词汇 → 第一课精读 → 第一次开口，
   全程不被打断；额度制功能每天够用一次完整练习。
2. **VIP 价值集中在三件事**：系统性内容（精读全部 14 课）、无限练习（AI/口语/新闻）、
   进阶路径（语法/听力/会话/商务）。词书和数据展示**退出 VIP 权益**（本来就是免费实现，
   不如大方写明，减少用户被欺骗感）。
3. **每一层都有「看得见的升级理由」**，但免费用户不被锁死在门口。

### 2.2 免费层（明确承诺，写进 VipPanel 免费说明）

| 内容 | 免费额度 | 说明 |
|---|---|---|
| 泰语发音入门 / 基础拼读 / 日常泰语表达 3 门课 | **每门前 3 课免费**（上线后） | 现状 coming，上线时按此标记 |
| 基础泰语精读 | 第 1 课免费试读（现状保持） | 唯一的「深度内容」钩子 |
| 视频学习库 | 每类 1 条免费（共 7 条） | 20 条里挑最精华的 7 条 |
| 全部 30 本词书 / 5234 词条 | **完全免费，明说不限** | 把现在的实现变成卖点 |
| 能力雷达 / 成长曲线 | **完全免费** | 同上 |
| AI 老师对话 | 10 次/天 | 维持现状 |
| 口语评测 | 单词模式 10 次/天 | 维持现状 |
| 新闻听音填空 | 10 题/天 | 维持现状 |
| 字母表 / 词汇配对 / 句子填空 / 分词练习 | 不限 | 练习类全免费 |

### 2.3 VIP 层（10 门课 + 无限练习）

| 权益 | 内容 |
|---|---|
| 全部课程 | 精读 14 课全开 + 上线后的 9 门进阶课全开 |
| 全部视频 | 视频库 20 条 + 各课全部课时 |
| 无限 AI 对话 | 含语音输入、情景模拟、文化讲解 |
| 完整口语训练 | 句子/段落跟读 + Azure 专业发音评测 |
| 无限新闻听力 | 听音填空不限题数 |
| 错题本智能复习 | 维持现状（如已免费则改为「智能间隔复习调度」为 VIP） |

### 2.4 落地改动清单（按优先级）

1. **改 VipPanel 文案（10 分钟，立即）**
   - 「5 门 VIP 进阶课程」→「10 门课程持续更新」
   - 删掉或改写「高级词汇与词书」「完整学习数据」两条 → 换成「精读全 14 课」「新课程抢先学」
   - 免费说明改为明确列出「词书/雷达永久免费」
2. **courses.js 与 lessons.js 的 free 标记按 2.2 重排（上线新课前）**
   - 免费课：前 3 课 `free: true`，其余 `free: false`（即使课程本身 isVip: false）
   - 让「免费课」不是全免费也不是全锁，而是可试读的完整体验
3. **词书/雷达的 VIP 文案下架**（若不想真做门控）
4. **加一个 `EntitlementSummary` 单一数据源**（建议）：
   把「哪个功能免费/额度/无限」收进一个 `src/lib/entitlements.js`，
   VipPanel、Course、Sidebar、配额提示都读它，杜绝「文案与实现漂移」——本次盘点发现的
   三处不一致就是这个问题的产物。

## 三、视频学习内容怎么办（现状：结构性缺内容）

### 3.1 现状问题（三个都成立）

1. **YouTube 依赖**：20 条视频全部 YouTube ID，大陆用户打不开 → 「视频学习」页在核心市场是空页。
2. **课时视频是占位**：64 个课时的 `videoUrl` 全指向 5 秒 flower.mp4，用户点开任何一课都是同一条花视频。
3. **本地真实素材没用上**：backend/videos 里 17 条真实泰国素材（合计约 20 分钟）零引用。

### 3.2 方案 A：本地化现有素材（1~2 天可完成，先救「能不能看」）

把 17 条本地视频按主题映射进视频库与课时，替换占位：

| 本地素材 | 时长 | 映射去向 |
|---|---|---|
| chiangmai-dance.mp4 | 11:26 | 文化课课时视频（culture-*）+ 视频库「泰国文化」类 |
| loy-krathong.mp4 | 4:01 | 文化类 / 真实会话节日课时（conv-08） |
| thai-street-food.mp4 | 3:14 | 日常类 / 点餐场景（daily-06） |
| thai-alphabet-lesson.mp4 | 3:20 | 发音课时（pronunciation-01/02） |
| grand-palace / wat-arun / wat-phra-kaew | 2:21 | 文化类 B 素材 |
| chiangmai-drone | 1:06 | 旅行类 |
| muay-thai / thai-royal-anthem | 1:18 | 文化类补充 |
| movie-300 | 5:00 | 听力类（listen-06 新闻/影视） |
| wikitonques-dang/tao | 4:23 | 听力类（发音相近词辨析） |
| bunny/sintel/friday/flower | — | 不进正式内容（纯占位） |

同时把 `lessons.js` 的 `DEFAULT_VIDEO` 改为「按课时映射的真实视频」，
没有对应素材的课时先标记「视频制作中」并隐藏播放按钮（不要放占位视频假播）。

**优点**：零成本、离线可播、大陆可用。
**缺点**：素材不是「泰语教学内容」，只是氛围/文化向 —— 适合垫底，不适合当课程主视频。

### 3.3 方案 B：YouTube 换源 + 代理（半天，解决「打不开」）

- 视频库 20 条 YouTube ID 保持，但播放器加**多源检测**：优先走本地 `localSrc`，
  检测 YouTube 不可达时降级为对应本地素材或显示「需科学上网」提示。
- 若服务器在境外（当前部署在 HK），可以直接做**后端视频代理**
  （`/api/video-proxy?v=<youtubeId>` 转流）—— 但 YouTube ToS 风险 + 带宽成本，不建议长期。
- 更现实：视频库每条增加 `bilibiliId` 字段，手工为 20 条视频配 B 站搬运/官方源，
  播放器按 `bilibiliId || youtubeId || localSrc` 顺序取源。

**已落地（先做了 5 条）**：视频库新增「中泰双语」分类，5 条全部是 B 站站外嵌入
（`bilibiliId` + `cover` + 双层出处：转载方 UP 主 + 原片频道），Course.jsx 按
`isEmbeddedSource()` 分流到 `player.bilibili.com` 官方播放器，卡片标「B 站」、
播放面板写清来源/原片/版权声明。这类条目是 UP 主的「转载」投稿，因此只做嵌入、
不下载不转码（下架＝删掉数据里那一条）。其余 20 条仍是 YouTube 源，待补 B 站源。
嵌入与封面均已实测：服务器端 API 元数据一致（片长/UP 主），播放器可匿名播放。

### 3.4 方案 C：自制视频内容（长期，真正的解）

课程真正的视频缺口是 **64 个课时没有教学视频**。建议按「拆课」思路做：

1. **优先做 3 门免费课的核心 9 个免费课时**（发音入门 3 + 拼读 2 + 日常 4）：
   每课 8~15 分钟的「教师出镜/屏幕录制 + 字幕」，免费层靠它们撑起完整体验。
2. **VIP 课用「AI 生成 + 人审」流水线**：
   - 脚本：现有 lessonData 的 title/description 已经是现成大纲，让 DeepSeek 按
     「讲解脚本 + 例句 + 停顿标记」格式生成（`字幕流水线.md` 已有基础）
   - 配音：现有本地 TTS 管线（`backend/tts.js`）直接生成泰语音轨
   - 画面：静帧图（本地已装 ComfyUI，可用 Qwen-Image 批量生成场景图）+ 字幕滚动 +
     Ken Burns 动效，用 ffmpeg 自动合成 —— **单课制作成本可以压到分钟级**
   - 人审后入库 `backend/videos/lessons/`
3. **格式统一**：1080p H.264 + 预生成 WebVTT 字幕（现有「字幕流水线」文档的格式），
   后端按 `/videos/lessons/<courseId>/<lessonId>.mp4` 发布，前端零改动。

### 3.5 推荐执行顺序

| 周 | 动作 | 效果 |
|---|---|---|
| 本周 | 方案 A（本地素材映射）+ 修 VipPanel 文案 | 视频页「有东西可看」、权益不再说谎 |
| 下周 | 方案 B（B 站源 + 多源播放器） | 大陆用户视频可用 |
| 第 3~4 周 | 方案 C 第一批：9 个免费课时自制视频 | 免费层完整闭环 |
| 之后 | 方案 C 批量：VIP 课时 AI 流水线 | 64 课时逐月补齐 |

## 四、一句话总结

**分层问题不大，问题在「说的和做的差三处」+「视频是空壳」。**
先把 VipPanel 文案改到与实现一致（10 分钟），再把本地 17 条真实素材映射进视频库（1 天），
免费层立刻从「承诺很多、内容很少」变成「内容诚实、可用」；64 个课时的教学视频用
「免费 9 课自制 + VIP 课 AI 流水线」在一个月内从 0 补到可用。

### 5.3 已完成：锁定规则统一（关键）

以前是 `course.isVip && !lesson.free && !isVipUser` —— 后果是**免费课（isVip: false）整门全开**，
「每门前 3 课试看」根本无法表达。现在统一为 `isLessonLocked({ lesson, isVipUser })`，
**只看课时自己的 `free` 标记**，与课程 isVip 解耦：

- `CourseDetail`：当前学习节点、继续学习入口、课时行锁定、LessonRow
- `LessonVideo`：本课锁定、自动连播、下一节按钮
- `LessonText`：音频课试读判定
- `Home`：从上次位置继续学习（顺带修掉 `last` 找不到时的崩溃隐患）
- `Course`：视频卡片锁定改走 `isVideoLocked`（视频库同规则）
