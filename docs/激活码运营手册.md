# ThaiAI 人工收款 + 激活码 运营手册（方案 A）

> 适用：无营业执照的个人 / 学生起步阶段，用「微信个人收款码收款 + 激活码开通 VIP」完成第一波商业化。
> 零平台风险、零审核、当天可上线。验证需求后再升级正式支付（个体户 + 微信官方 API）。

---

## 一、整体流程

```
用户看到 VIP 页 → 加你微信 → 转账 → 你确认到账 → 管理端生成激活码 → 发给用户 → 用户输入激活码 → VIP 自动开通
```

全程只有「转账 → 发码」两个人工动作，其余全部系统自动。

---

## 二、上线前准备（一次性，约 30 分钟）

### 1. 准备收款码
- 微信 → 我 → 服务 → 收付款 → 我要收款 → 保存收款码图片
- 建议：打印出来贴在电脑旁，或存手机相册置顶

### 2. 建立客服微信 / 群
- 用你自己的微信即可（或注册一个专门客服号）
- 建议建一个「ThaiAI 泰语学习」微信群：发通知、答疑、晒学员成果（也是获客渠道）

### 3. 准备价格表（放简介/群公告）
```
ThaiAI VIP 会员（人工收款价目）
  月度会员  ¥49    / 30 天
  季度会员  ¥128   / 90 天
  年度会员  ¥399   / 365 天
收款方式：微信转账
付款后 10 分钟内发激活码，节假日顺延
```

### 4. 确认管理端入口
- 用管理员邮箱（`.env` 里 `ADMIN_EMAILS`）注册/登录
- 个人中心 → 管理工具 → 发码页面（`/admin/codes`）

---

## 三、日常发码流程（每次约 1 分钟）

### 1. 用户转账后
确认微信已到账（金额与价目一致）。

### 2. 生成激活码
管理端发码页 → 填「数量 1 + 天数」→ 生成 → 复制该码。

### 3. 发给用户
微信回复（建议复制这段话）：

```
感谢购买 ThaiAI VIP 🎉
你的激活码：XXXX-XXXX-XXXX
开通方式：登录后 → 我的 → VIP 会员 → 激活码 → 粘贴输入 → 立即开通
有效期 30/90/365 天，用完请告知我续费～
有问题随时找我！
```

### 4. 提醒用户开通
- 用户激活后系统自动生效，无需你操作
- 若用户不会操作，引导：登录 → 个人中心 → 免费版·了解VIP权益 → 激活码页签

## 四、管理端发码页功能（已内置）

| 功能 | 入口 | 说明 |
|---|---|---|
| 批量生成 | 数量 + 天数 + 前缀 | 一次性生成 N 个码（如开课团购 20 个 30 天） |
| 列表/筛选 | 状态筛选 | 未使用 / 已使用 / 全部 |
| 导出 CSV | 导出按钮 | 批量发码时导出 Excel 表格 |
| 使用追踪 | 列表详情 | 每个码显示：用了谁的邮箱、何时使用 |

**批量场景（开课/团购/赠课）**：生成 20 个码 → 导出 CSV → 群发/私发即可，不用一个个生成。

## 五、常见用户问题应答

| 用户问 | 你答 |
|---|---|
| 为什么不是直接扫码支付？ | 目前人工开通更优惠，微信转账后 10 分钟内发码（其实是在线支付还没接） |
| 激活码是什么？ | 一串专属代码，输入后 VIP 立即生效，类似充值卡密 |
| 可以开发票吗？ | 目前为个人服务，暂不支持发票（后续办执照后可开） |
| 到期后还能学吗？ | 免费课程仍可学，VIP 内容到期锁定，续费即恢复 |
| 能退款吗？ | 未激活可退；已激活的码不支持退款（可协商换套餐） |

## 六、风控与注意事项

1. **只认到账，不认截图**——以你微信零钱/银行实际到账为准
2. **收款码和客服微信号分开管理**——收款码用个人码，客服回复用客服号（避免混淆）
3. **保留聊天记录**——转账记录 + 发码记录都留着，方便售后对账
4. **激活码不回收**——已发给用户的码即使未激活也不要再给别人（系统记录可查）
5. **微信风控**——大额频繁转账可能触发风控，单笔建议 ≤5000 元；月流水高了再考虑升级正式支付
6. **个人码收款限制**——微信个人收款码有单日收款额度（一般几万内），达标后当日不可再收，需次日

## 七、升级路线（验证成功后）

| 时机 | 升级动作 | 说明 |
|---|---|---|
| 有稳定付费用户（比如月入 500+） | 办个体工商户 | 成年学生可办，几百块，几天下证 |
| 执照到手 | 申请微信支付**普通商户** | 教育/知识付费行业可签约，费率 0.6%，资金直达银行卡 |
| 拿到商户号 | 填 `PAY_WECHAT_*` 到 `.env`，删 `PAY_WECHAT_MOCK` | 微信 Native 扫码支付代码已就绪，前端零改动，自动切换 |

**人工收款期约等于 0 成本**，等月收入能覆盖执照+服务器费用时再升级，风险最小。
