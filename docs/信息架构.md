# ThaiAI 信息架构（IA）与页面职责规范

> 本文件是「每个页面负责什么、什么内容该出现在哪里」的唯一约定。
> 新增页面前先读这里；改导航前先改 `src/lib/navigation.js`。
>
> 最近一次全站重构的结论与依据见文末「重构记录」。

---

## 一、三条原则

1. **一个能力只有一个权威入口。**
   同一件事有第二个入口时，第二个入口必须降级为「快捷方式」（直接跳到权威入口），
   不允许各自实现一套界面或数据。
2. **页面职责由「用户此刻想做什么」划分，不由「功能模块」划分。**
   所以「今天要学什么」和「内容库」是两类页面，而不是把课程/词汇/口语各开一页。
3. **卡片留给真的是卡片的对象。**
   分区用排版（标题 + 发丝分割线）表达，不用一叠 `premium-glass` 大卡；
   只有「一门课、一个词、一条错题」这种可点选的对象才用卡片。

## 三、导航规范

**唯一事实来源：`src/lib/navigation.js`。**
桌面侧边栏（`Sidebar.jsx`）与移动底部栏（`MobileTabBar.jsx`）都从它派生，
两者**只允许在「取舍」上不同**（底部栏放不下就少放几个），
不允许在「同一功能叫什么、指向哪」上不同。

三组：

- **今天** — 首页 / 今日闭环 / AI 对话室 / 学习宇宙
- **内容** — 课程学习 / 课文教学 / 媒体学习 / 文化宇宙 / 本地语料库
- **更多** — 词汇星球 / 口语练习 / 练习中心 / 我的旅程 / 字母表 / 泰国文化 / 专业方向 / 学习战绩 / 设置中心

移动底部栏（≤5 项，AI 为中间主按钮）：
首页 · 今日闭环 · **AI 对话室** · 词汇星球 · 我的

### 字段约定

| 字段 | 含义 |
|---|---|
| `flag` | 功能开关名；关掉时两端一起消失（不要让每页自己判） |
| `tabs` | 是否进移动底部栏 |
| `mobileOnly` | 只在移动端出现（如「我的」——桌面由侧边栏用户卡承担） |
| `hidden` | 不在常规菜单出现，但 `findNavItem` 仍能解析归属 |
| `badge` | `vip` / `partial` / `new` |
| `match` | 额外的高亮前缀（父子路由、旧路径） |

**加新页面时**：在 `navItems` 加一项 → 在 `App.jsx` 注册路由 →
加入 `routePrefetch`。三处路径必须一致。

## 四、视觉规范

| 用途 | 用什么 |
|---|---|
| 页面外壳（宽度 + 页头） | `PageShell`（`SHELL_WIDTH`: reading / default / wide） |
| 分区标题 | `Section`（默认 `plain`：发丝分割线，不叠卡） |
| 分区内网格 | `SectionGrid` |
| 数字块 | `StatTile` |
| 列表行 | `RowItem` |
| 真的是卡片的对象 | `GlassCard`（`premium.jsx`） |
| 页面级沉浸首屏 | `WorldHero` |

**禁止**：在新页面里手写 `rounded-[26px]` 这类一次性半径，或为「一个分区」套一张
`premium-glass` 大卡。同一屏内的卡片半径、边框、模糊必须一致。

## 五、数据规范

- **XP / 等级 / 连续天数**：唯一写入方是 `useLearningProgress`；
  唯一等级曲线是 `lib/level.js`。任何页面不得自造积分公式或等级名。
- **答对/答错结算**：练习类页面统一调 `usePracticeReward()`，
  不要自己 `setScore` 了事（本地分数只做即时反馈）。
- **错题本**：唯一存储是 `lib/wordBooks` 的 `thaiai-wrong-notebook`；
  读写一律走 `recordWrongWord` / `fetchWrongBook` / `removeWrongWord`。
- **连续打卡**：服务端 `GET /api/plan/overview` 优先，本地值仅作兜底。
- **异步取数**：用 `useAsyncData`，不要在页面里裸写 `fetch` + 三个 state。

## 六、重构记录（2026-09-20）

依据两份只读审计（38 个页面逐页清单 + 重复实现/Top 8 问题）。

**改掉的**

1. **三套互相矛盾的导航** → `navigation.js` 单一事实来源。修掉移动端丢失
   `/practice`、`/profile` 入口的回归；底部栏补回「我的」。
2. **词汇练习不产出 XP**（审计 Top 1）→ 新增 `usePracticeReward`，
   配对/填空/分词/测验四个模式答对即写入学习进度，答错统一进错题本。
   此前 `WordSegment` 完全不记错题。
3. **错题本两套存储不互通** → 统一 `lib/wordBooks`；`VocabQuiz` 不再按
   `vocabulary_id` 另写一份（同一个词会写两条）。页面此前读 base44
   实体，永远是空的。
4. **`/ranking` 假数据 + `/challenges` 空榜** → `/ranking` 改为真实战绩
   （连续天数/XP/本周打卡/里程碑），明确标注「排行榜尚未开放」而不放假数据；
   `/challenges` 重定向到 `/ranking`（外部 base44 无对应后端接口）。
5. **口语两个外壳** → `/speaking-practice` 重定向；删掉永不可达的
   standalone 分支与 `Navbar`。
6. **`Profile` 周目标硬编码 72%** → 由 `daily_history` / 口语记录 /
   服务端打卡推导。
7. **`Settings` 条件调用 hook**（rules-of-hooks，切身份会崩）→ 守卫移到
   hooks 之后。
8. **`routePrefetch` 与实际入口不符** → 与新导航对齐。

**删掉的死代码**（均无任何引用，git 历史可恢复）

`components/Navbar.jsx`、`components/ProgressDashboard.jsx`（等级逻辑恒错）、
`components/VocabularyCard.jsx`、`components/wrong-notebook/WrongNotebookItem.jsx`、
`pages/Challenges.jsx`（外部通道无后端，见第 4 条）。

**留待后续（需要产品决策或后端支持）**

- **口语评分 4 个入口**（对话室 / 口语练习 / 新闻听力 / 首页守护者）底层都打
  `/speaking/analyze`：应收敛为一个「评分服务层」，目前只统一了记录写入路径。
- **`/media` 与 `/culture-universe` 共用 `mediaLessons`**：分类命名不同
  （媒体学习 vs 泰剧世界/音乐工作室），需决定哪一个是权威入口。
- **课程双轨**：`/course`（`data/videoLibrary` + `thaiai_video_progress_*`）与
  `/course/:id`（`data/courses` + `thai_ai_course_progress_v1`）数据与进度都
  不互通，需要一次迁移。
- **公开排行榜**：后端提供接口后恢复 `/ranking` 的榜单区（结构已留好）。
- **`/thai-landing`、`/__assets`**：无入站链接的隔离页，是否保留待确认。
